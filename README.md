# Tiefsee for Android

Неофициальная Android-версия [Tiefsee](https://github.com/hbl917070/Tiefsee4) — открытого просмотрщика изображений от hbl917070.

Оригинал написан под Windows (C# + WebView2), поэтому это не «пересборка», а новое нативное приложение на Kotlin, которое повторяет функции Tiefsee. Сторонних библиотек нет — только стандартный Android API (Android 8.0+).

## Что умеет

| Tiefsee (Windows) | Android-версия |
|---|---|
| Форматы: JPG, PNG, GIF, WebP, APNG, BMP, ICO, HEIC, AVIF, SVG, PSD, CLIP, QOI | Всё перечисленное (HEIC — Android 9+, AVIF — Android 12+). PSD/PSB, CLIP и QOI — собственные декодеры |
| Видео WebM, MP4 | WebM, MP4, MKV, MOV, 3GP |
| Просмотр архивов без распаковки | ZIP, CBZ, TAR, CBT (файлы извлекаются по требованию) |
| File Panel | Лента миниатюр соседних файлов внизу просмотрщика |
| Folder Panel | Браузер папок с превью первой картинки, избранное, недавние |
| Information Panel | EXIF, GPS (открыть на карте), AI-промпты: A1111/Forge, NovelAI, ComfyUI, InvokeAI |
| Bulk View | Вертикальная лента всех картинок (1–4 колонки, щипок меняет колонки) |
| Поиск по картинке | SauceNAO, Yandex, Ascii2d, Google Lens, Bing |
| QuickLook | Долгое нажатие на файл → «Быстрый просмотр» |
| Open Web Image | «Поделиться» ссылкой на картинку из браузера → Tiefsee скачает и откроет |
| PDF reader, MD editor, text editor, docx/pptx reader | Всё есть: PDF (с зумом страниц), Markdown с предпросмотром, текстовый редактор, DOCX/PPTX с картинками и таблицами |
| Языки: English, 中文 | English, Русский, 繁體中文 |

Плюс: зум щипком и двойным тапом, подгрузка участка в полном разрешении при сильном увеличении (огромные фото и сканы остаются чёткими), поворот, отражение, режимы масштаба (вписать / по ширине для манги / 100%), слайд-шоу, тёмная/светлая тема, 7 акцентных цветов, шахматный фон для прозрачности, переименование, удаление, «Открыть с помощью», «Установить как обои», клавиатура и колёсико мыши на планшетах.

## Как получить APK

### Вариант 1 — GitHub Actions (компьютер не нужен для сборки)

1. Создайте новый репозиторий на github.com.
2. Загрузите в него **содержимое** этой папки (так, чтобы `.github`, `app`, `settings.gradle.kts` лежали в корне репозитория). С компьютера: на странице репозитория «Add file → Upload files» и перетащите всё содержимое папки.
3. Сборка запустится автоматически (вкладка **Actions**, ~5 минут).
4. Готовый `Tiefsee-Android.apk` появится в **Releases** (и в артефактах сборки).
5. Скачайте APK на телефон и установите (разрешите установку из этого источника).

### Вариант 2 — Android Studio

Откройте папку проекта в Android Studio → Build → Build APK(s).

## Первый запуск

Приложение попросит «Доступ ко всем файлам» — без него нельзя листать соседние файлы папки, открывать архивы, переименовывать и удалять (так работает любой файловый просмотрщик на Android 11+).

## Заметки

- Поиск по картинке работает как в Tiefsee для Windows: картинка уменьшается и загружается на временный сервер автора Tiefsee, затем открывается страница поисковика.
- APK подписан ключом из `keystore/` — новые сборки ставятся поверх старых без удаления. Если будете публиковать приложение, замените ключ на свой.
